# gd-rtc
Online multiplayer Geode mod for Geometry Dash using Web-RTC and Firebase RTDB.
Inspired by Globed, vibe coded, and completely original code.
Only use this if you can't use Globed, as it is better in every way.
Beware of using this on metered connections, as WebRTC uses bandwidth for each connected player.

Geometry Dash: https://geometrydash.com/

Geode: https://geode-sdk.org/

Globed: https://globed.dev/
