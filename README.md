# gd-rtc
Online multiplayer using Web-RTC and Firebase RTDB.
Inspired by Geode, vibe coded, and completely original code.
Only use this if you can't use Globed, as it is better in every way.
Beware of using this on metered connections, as WebRTC uses bandwidth for each connected player.
